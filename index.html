CORS 프록시 설정

브라우저는 다른 사이트의 내용을 바로 읽지 못하는 경우가 많습니다(CORS). 직접 요청이 실패하면 아래 프록시를 순서대로 시도합니다. 한 줄에 하나씩, 대상 주소가 들어갈 자리에 {url}(인코딩) 또는 {raw}(그대로)를 쓰세요. 입력한 내용은 이 브라우저에만 저장됩니다.

사용 가능: {name} 이름, {n} 순번, {orig} 원래 파일명, {alt} 이미지 설명. 확장자는 자동으로 붙습니다. 선택한 순서가 아닌 목록 순서대로 번호가 매겨집니다. Shift+클릭으로 범위 선택.

조건에 맞는 이미지가 없습니다.
